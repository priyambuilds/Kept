# packages/

Shared TypeScript libraries used by `frontend` (frontend-side).

| Folder | What |
|---|---|
| `config/` | constants (objects, gestures, stakes, lengths) and the tsconfig/eslint presets |
| `shared/` | zod schemas and API contract types |
| `engine/` | pure rules: HP, miss cost, distribution, Rematch, kept rate, odds; `test-vectors/` JSON |
| `chain/` | program client: IDL, PDAs, account decoding, instruction builders |
